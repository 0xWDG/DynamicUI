# DynamicUI Roadmap

This roadmap describes direction rather than guaranteed release dates. Feature requests and focused
contributions are welcome.

## Current

- Versioned layout envelopes and schema validation
- Application-defined component rendering
- First-class accessibility metadata
- Documentation and playground coverage for supported views

## Next

- Structured validation diagnostics that can report multiple issues at once
- A published machine-readable JSON Schema
- More custom-renderer examples, including interaction routing
- Automated accessibility coverage in the playground application
- Expanded modifier coverage with consistent platform fallbacks

## Later

- Schema migration helpers
- Optional caching and fallback examples for remotely loaded layouts
- Additional native SwiftUI components driven by community demand
- Tooling for previewing and validating payloads outside an application

Vote on existing feature requests with reactions or open a proposal using the feature-request form.
